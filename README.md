# Rivka_Dikstein_Lab
Laboratory equipment ordering website managed by Dr. Anat Bahat.

[Open the equipment ordering site](https://ehudelfer.github.io/Rivka_Dikstein_Lab/)

The site is published from `equipment_orders/templates/index.html` with GitHub
Actions. To enable publishing, open the repository's **Settings > Pages** and
set **Build and deployment > Source** to **GitHub Actions**. Each push to
`main` that changes the page or its deployment workflow will then publish it.
